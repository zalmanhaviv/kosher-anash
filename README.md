# כשר לאנ״ש

מאתר מסעדות כשרות לאנ״ש, מתוך מאגר מסעדות לאנ״ש חב״ד. אתר סטטי (PWA), עברית, מתארח ב-Netlify.

## מבנה
- `data/places.json` – המאגר. כל מקום: שם (`n`), רחוב (`s`), ישוב (`c`), סוג מקום (`k`), כשרות כפי שבמאגר (`h`) וסיווגה (`hc`), סוגי אוכל (`t`), שעות מגוגל (`g.periods`, יום 0 = ראשון) וחודש הבדיקה (`g.chk`).
- `data/cities.json` – מרכזי ישובים.
- `src/template.html` – האפליקציה.
- `public/` – קבצים סטטיים (Service Worker, אייקונים, כותרות אבטחה).
- `scripts/validate.py` – בדיקת המאגר. רץ אוטומטית לפני כל בנייה.
- `scripts/build.py` – בונה את `dist/`.

## כללים
- סיווג הכשרות מוצג בדיוק כפי שהוא במאגר. לא משנים ולא מפרשים.
- לא ממציאים שעות. בלי שעות שפורסמו: "אין מידע על שעות הפעילות".
- לא מניחים סגירה בכניסת שבת. זמני הדלקת נרות לפי מנהג חב״ד (18 דק׳, ירושלים 40).
