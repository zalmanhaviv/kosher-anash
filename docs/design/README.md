# כיווני עיצוב – כשר לאנ״ש (S1-2)

שלושה כיוונים לבחירת הבעלים. **שום דבר לא מומש באפליקציה** – אחרי הבחירה, design-system מממש את הכיוון ב-`:root` וב-`public/map-style/`.

בכל ההדמיות הנתונים אמיתיים: מקומות מצפת והסביבה מתוך `data/places.json`, הכשרות מילה במילה, והסטטוס חושב ב-`statusAt` (`src/logic.js`) ליום שישי 27.11.2026 בשעה 12:30, שעון ישראל, עם הסינון "פתוח עכשיו". הדלקת נרות בצפת: 16:14 (מנהג חב״ד). המפה בהדמיות היא שרטוט בצבעי הסגנון, לא אריחים אמיתיים. הגופנים הוחלפו בצילומים בגופני מערכת, כי בסביבת העבודה אין רשת.

## המלצה
**נרות.** זה הכיוון היחיד שהופך את הבידול של המוצר, יום שישי והדלקת נרות לפי מנהג חב״ד, לחלק מרכזי בעיצוב ולא להערה. הוא גם פותר את הבעיה מהביקורת (כחול המותג מול חב״ד ומול נקודת המיקום) בשינוי הקטן ביותר למבנה הקיים.
