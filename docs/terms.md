# מילון מונחים

אותו דבר נקרא תמיד באותו שם, בכל מסך.

| מונח | משמש ל | לא לכתוב |
|---|---|---|
| מקום / מקומות | כל רשומה במאגר (מסעדה, מאפייה, מוצרים) | עסק, נקודה |
| ישוב | עיר או ישוב | עיר, יישוב |
| פתוח עד HH:MM | פתוח עכשיו לפי שעות שפורסמו | פתוח כעת |
| נסגר בעוד N דק׳ | נסגר בתוך שעה | עומד להיסגר |
| נפתח היום / מחר / ביום X ב־HH:MM | סגור עכשיו, ידוע מתי נפתח | |
| סגור עכשיו | סגור לפי שעות שפורסמו | |
| אין מידע על שעות הפעילות | אין שעות שפורסמו. לעולם לא מנחשים. | שעות לא ידועות, ? |
| פתוח בליל שישי (לפי המאגר), השעות לא ידועות | מקום שהמאגר מציין רק "ליל שישי" | פתוח בליל שישי (בלי הסתייגות) |
| נסגר לצמיתות / סגור זמנית (לפי גוגל) | סטטוס סגירה מגוגל | |
| כשרות | שם גוף הכשרות כפי שבמאגר, מילה במילה | השגחה, הכשר |
| הדלקת נרות | זמן לפי מנהג חב״ד | כניסת שבת |
| ניווט / גוגל מפות / שיתוף / חיוג | כפתורי הפעולה | |
| איתור מיקום | בקשת GPS | הפעלת מיקום |
| ניקוי סינון | איפוס כל הסינונים | איפוס, נקה |
| מקומות אוכל | סוג המקום "מסעדה" במאגר (כל פרק המסעדות: פיצה, מאפיות, מסעדות…) | מסעדות ומאפיות |
| מסעדות | סוג האוכל "מסעדה" בלבד – אותו שם בצ׳יפ ובסינון. כך גם "מאפיות", "בשרים וגריל" | מסעדה (בתווית) |
| N פתוחים · M בלי מידע על שעות | כותרת הרשימה כש"פתוח עכשיו" פעיל. N = המספר שבצ׳יפ | |
| N דק׳ הליכה / N ק״מ | מרחק מהמיקום של המשתמש (GPS) למקום עם מיקום מדוייק | |
| בערך N ק״מ / ב<ישוב> | מרחק למקום שהמיקום שלו משוער (ברמת הרחוב או רק ישוב) | ~N ק״מ |
| בסביבה · המרחק ממרכז <ישוב> | כשנבחר ישוב בלי GPS: כותרת הקבוצה. המרחק נמדד ממרכז הישוב, במספר שלם, ובלי זמן הליכה. בשורות שמתחתיה רק "N ק״מ" | דק׳ הליכה |
| N ק״מ ממרכז <ישוב> | אותו מרחק, בכל מקום שאין מעליו את הכותרת: כרטיס המקום, מיון לפי שם, מצב שישי, הרשימה שלי | N ק״מ (בלי הקשר) |
| המיקום במפה משוער (לפי מרכז הישוב) / (ברמת הרחוב) | בראש כרטיס של מקום בלי מיקום מדוייק | |
| המקומות בלי מיקום מדוייק מופיעים ברשימה | הודעה קצרה אחרי לחיצה על תג "N מקומות ב<ישוב>" במפה | …ברשימה של <ישוב> |
| אין כתובת במאגר | מקום שאין לו רחוב במאגר | כתובת לא ידועה |
| לא נמצאה התאמה מדוייקת ל״…״. מוצגות תוצאות דומות. | חיפוש שתוקן אוטומטית (שגיאת הקלדה; ההתאמה גם לפי רחוב, ישוב וכשרות) | האם התכוונת, מקומות עם שם דומה |
| לא נמצאו מקומות · אפשר להרחיב: | רשימה ריקה, עם כפתורים שיש להם תוצאות בלבד (עם המספר) | |
| כל הסוגים (בשרי, חלבי ופרווה) | כפתור הרחבה ברשימה ריקה שמבטל את סינון בשרי/חלבי/פרווה | בשרי, חלבי ופרווה (לא ברור שזה איפוס) |
| נסו מילה אחרת או פחות סינונים. / נסו פחות סינונים. | רשימה ריקה בלי הצעות להרחבה, עם חיפוש / בלי חיפוש | |
| הוספה למסך הבית | התקנת האפליקציה (כרטיס, כפתור בסוף הרשימה, הדרכה באייפון) | התקנה, הורדה |

עיצוב: כל הצבעים, הגדלים, הרווחים, הרדיוסים ומשכי התנועה מוגדרים ב-`:root` בתחילת `src/template.html`. אין להוסיף ערך קשיח מחוץ לשם.

נוסחים נוספים:
- **מדוייק / מדוייקת** – כך בכל הממשק, כמו בנוסח הבעלים "נראה שהמידע אינו מדוייק" (שמובא מילה במילה).
- **הדרכת אייפון, צעד 1:** "בספארי, לוחצים על כפתור השיתוף" – "בסרגל של ספארי, בתחתית המסך או למעלה. אם הכפתור לא מופיע, לוחצים קודם על ⋯" (ב-iOS 26 בפריסה הקומפקטית השיתוף נמצא בתפריט ⋯). צעד 2: "אם לא רואים, גוללים למטה ברשימה או פותחים את כל האפשרויות".
- **פרטיות (תחתית הרשימה):** "פרטיות: המיקום שלך משמש רק במכשיר, לחישוב המרחק. הוא לא נשלח ולא נשמר. אריחי המפה של האזור שבמסך נטענים מ-OpenFreeMap, והנתונים מ-GitHub. אין מעקב ואין פרסומות." לא לכתוב "המיקום נשאר במכשיר" בלי ההסתייגות על האריחים (האזור שבמסך כן נחשף ל-OpenFreeMap).
