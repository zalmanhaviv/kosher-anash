# מילון מונחים

אותו דבר נקרא תמיד באותו שם, בכל מסך.

| מונח | משמש ל | לא לכתוב |
|---|---|---|
| מקום / מקומות | כל רשומה במאגר (מסעדה, מאפייה, מוצרים) | עסק, נקודה |
| ישוב | עיר או ישוב | עיר, יישוב |
| פתוח עד HH:MM | פתוח עכשיו לפי שעות שפורסמו | פתוח כעת |
| נסגר בעוד N דק׳ | נסגר בתוך שעה | עומד להיסגר |
| נפתח היום / מחר / ביום X ב־HH:MM | סגור עכשיו, ידוע מתי נפתח | |
| סגור עכשיו | סגור לפי שעות שפורסמו | |
| אין מידע על שעות הפעילות | אין שעות שפורסמו. לעולם לא מנחשים. | שעות לא ידועות, ? |
| פתוח בליל שישי (לפי המאגר), השעות לא ידועות | מקום שהמאגר מציין רק "ליל שישי" | פתוח בליל שישי (בלי הסתייגות) |
| נסגר לצמיתות / סגור זמנית (לפי גוגל) | סטטוס סגירה מגוגל | |
| כשרות | שם גוף הכשרות כפי שבמאגר, מילה במילה | השגחה, הכשר |
| הדלקת נרות | זמן לפי מנהג חב״ד | כניסת שבת |
| ניווט / גוגל מפות / שיתוף / חיוג | כפתורי הפעולה | |
| איתור מיקום | בקשת GPS | הפעלת מיקום |
| ניקוי סינון | איפוס כל הסינונים | איפוס, נקה |
| מקומות אוכל | סוג המקום "מסעדה" במאגר (כל פרק המסעדות: פיצה, מאפיות, מסעדות…) | מסעדות ומאפיות |
| מסעדות | סוג האוכל "מסעדה" בלבד – אותו שם בצ׳יפ ובסינון. כך גם "מאפיות", "בשרים וגריל" | מסעדה (בתווית) |
| N פתוחים · M בלי מידע על שעות | כותרת הרשימה כש"פתוח עכשיו" פעיל. N = המספר שבצ׳יפ | |
| N דק׳ הליכה / N ק״מ | מרחק מהמיקום של המשתמש (GPS) למקום עם מיקום מדויק | |
| בערך N ק״מ / ב<ישוב> | מרחק למקום שהמיקום שלו משוער (ברמת הרחוב או רק ישוב) | ~N ק״מ |
| בסביבה · המרחק ממרכז <ישוב> | כשנבחר ישוב בלי GPS: המרחק נמדד ממרכז הישוב, במספר שלם, ובלי זמן הליכה | דק׳ הליכה |
| המיקום במפה משוער, לפי מרכז הישוב / ברמת הרחוב | בראש כרטיס של מקום בלי מיקום מדויק | |
| אין כתובת במאגר | מקום שאין לו רחוב במאגר | כתובת לא ידועה |
| לא נמצאה התאמה מדויקת ל״…״. מוצגים מקומות עם שם דומה. | חיפוש שתוקן אוטומטית (שגיאת הקלדה) | האם התכוונת |
| לא נמצאו מקומות · אפשר להרחיב: | רשימה ריקה, עם כפתורים שיש להם תוצאות בלבד (עם המספר) | |
| הוספה למסך הבית | התקנת האפליקציה (כרטיס, כפתור בסוף הרשימה, הדרכה באייפון) | התקנה, הורדה |

עיצוב: כל הצבעים, הגדלים, הרווחים, הרדיוסים ומשכי התנועה מוגדרים ב-`:root` בתחילת `src/template.html`. אין להוסיף ערך קשיח מחוץ לשם.
